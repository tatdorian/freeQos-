Links: throughput, capacity, source

The plan belongs to each client. A site (PoP) is only a connection point: it has a capacity, not a plan. A client's plan is pushed by your billing through the API (PUT /model/v1/services, as often as needed), or set here. The last one written wins. A client pushed without a rate gets the default plan; a client only detected on a router is observed, not capped, unless Settings applies the default plan to detected clients too.
