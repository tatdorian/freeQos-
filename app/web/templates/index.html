Backhauls radio

Vrai arbre reseau, editable : glissez une case pour la deplacer, deposez-la sur une autre pour la rattacher. Chaque lien porte son debit mesure, chaque PoP ses abonnes. La disposition et les rattachements sont enregistres — ils ne changent que l'arbre AFFICHE, aucun equipement n'est reconfigure.

Tableau des liens · l'arbre est dans l'onglet Arbre reseau

Le debit vient des compteurs du PORT qui porte le lien (/interface, deux lectures successives) : → ce que le routeur emet vers l'equipement d'en face, ← ce qu'il en recoit. Debit ouvre l'historique et permet de demander une mesure instantanee au routeur.

Journal des commandes envoyees

Ajoutez un routeur ou une antenne via son API : le controleur lit sa configuration (/ip/neighbor, /interface, capacite radio) et construit l'arbre reseau tout seul. Chaque ajout relance l'analyse ; l'arbre se voit dans l'onglet Topologie.

Antennes Ubiquiti (capacite radio)

Interrogees directement sur leur API airOS locale, sans UISP. La capacite lue devient le debit parent du shaping du lien. Ajouter une antenne ici suffit : aucune variable d'environnement, aucun redemarrage.
